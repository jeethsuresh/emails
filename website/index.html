What it is

Email is a desktop client for IMAP/SMTP accounts. It is built for people who want their mail available when the network is not, and who prefer a local store over a hosted webmail tab. v1 signs in with an IMAP/SMTP password.

  • Folders, threads, search, star/unread, drafts, and compose/send
  • Calendar (CalDAV / ICS) beside the inbox
  • Optional on-device analysis for suggested replies and events
  • Data on disk under ~/.emails/ (override with EMAIL_HOME)

How it works

UI

Electron + React. The window never talks to IMAP itself.

Local store

PocketBase (Go) on localhost holds accounts, folders, messages, and calendar.

Sync sidecar

A native Go process syncs IMAP/SMTP and CalDAV in the background.

Hot paths

C compiled to WASM for MIME headers, tokenize, and contact normalize.

The renderer talks to PocketBase through Electron IPC. If sync fails, local mail still opens. Status is idle, syncing, error, or offline — never a blocking spinner over the whole app.

Install

macOS (Apple Silicon)
Open the .dmg, drag Email into Applications, then right-click → Open once to bypass Gatekeeper.
Windows
Run the NSIS installer. If SmartScreen appears, choose More info → Run anyway.
Ubuntu / Debian
sudo apt install ./Email-*-linux-x64.deb
Fedora / RHEL
sudo dnf install ./Email-*-linux-x64.rpm
Arch / Manjaro
sudo pacman -U ./Email-*-linux-x64.pacman
Any Linux
chmod +x Email-*-linux-x64.AppImage && ./Email-*-linux-x64.AppImage

Local-first. No hosted mailbox. Issues and source on GitHub.
